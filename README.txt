WEBSITE PROYEK BAB 5 IPTEK — IPTEK QURANI

Isi folder:
- index.html : struktur dan seluruh isi website
- style.css  : desain, responsif, dan animasi
- script.js  : menu mobile, scroll progress, dan animasi saat scroll

Cara menjalankan:
1. Ekstrak file ZIP.
2. Buka folder website_iptek di Visual Studio Code.
3. Buka index.html menggunakan browser, atau gunakan ekstensi Live Server.
4. Untuk mengubah isi, edit teks pada index.html.
5. Untuk mengubah warna/tampilan, edit variabel di bagian :root pada style.css.
